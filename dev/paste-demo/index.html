貼り付けの動作デモ(案 A: 画像とテキストの両方があるときに選ぶ)

試し方:
  1. Excel でセルを選んで Ctrl+C → 左のエディタで Ctrl+V → メニューから選ぶ
  2. Ctrl+Shift+V はメニューを出さずにテキストで貼り付ける
  3. スクリーンショットなど画像だけのときはメニューなしで画像として貼り付く
  4. 画像の保存中にもう一度貼り付けても受け付けない
  5. Alt+Shift+F か「表を整形」ボタンで表の列を揃える
  6. Excel の画像をコピーして下の「注釈エディタと同じ条件で試す」枠をクリック → Ctrl+V
※ これはデモです。貼り付けた画像はブラウザのメモリ上に保持するだけで、ファイルには保存しません。
