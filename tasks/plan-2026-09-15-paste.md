## 1. 注釈エディタで Excel の画像を Ctrl+V で貼れない(不具合)

### 原因(2026-09-15 デモページで実機確認済み・確定)
- 実機の Excel の画像のコピー: items は 1. string:image/svg+xml(空文字)2. file:image/png(1,177,379 bytes)の順。
  今の処理は 1 を選んで失敗、修正後の処理(kind === 'file')は成功
- `src/annotator/annotator.js` の `_pasteHandler` は clipboardData.items から「type が image/ で始まる
  **最初の項目**」を選んで `getAsFile()` している。kind(file / string)を見ていない
- Excel の画像のコピーには、画像のファイル項目(file:image/png)の前に、画像形式の文字列項目
  (例: string:image/svg+xml)が入っていると考えられる。文字列項目の getAsFile() は null なので、何も起きない
- md のエディタ(`src/paste.js`)は `kind === 'file'` の項目だけを見るので貼れる。画像編集ソフトを
  経由するとクリップボードがビットマップだけになるので注釈エディタでも貼れる(症状と一致)

### 対応
- `_pasteHandler` を `kind === 'file'` かつ type が image/ の項目から選ぶように直す(src/paste.js と同じ条件)
- 「画像を追加」のツールチップに「Ctrl+V・ドラッグ&ドロップでも追加できます」を追記
  (「貼り付け」ボタンは作らない。Ctrl+V が使えることを確認済みのため)
- E2E: 文字列の image/svg+xml を先、ファイルの image/png を後に入れた貼り付けで画像が追加される
  (修正前のコードで失敗することも確認)
- 注意: annotator.js は feature/elbow で変更中。elbow が dev に入ってから着手する

## 2. md への画像の貼り付けが遅く、二重に貼ってしまう

### 原因(コードで確認)
- `src/paste.js` の `handleFiles()` は画像ファイルの保存が **終わってから** `![](...)` を挿入する。保存中は画面に何も出ない
- 不具合: 保存中にもう一度貼り付けると 2 つの保存が並行して同じ連番(image-N)を求め、後の画像が前の画像を上書きする

### 対応
- 貼り付け・ドロップした瞬間に挿入位置へ「⏳ 画像を保存中…」を出す(CodeMirror のウィジェット。本文には書き込まない)
- 保存が終わったらその位置に `![](...)` を挿入。失敗したら表示を消してエラー
- 保存中の画像の貼り付け・ドロップは受け付けない(「前の画像を保存中です。保存が終わってから貼り付けてください」)
- 保存中に別の md に切り替えたら参照を挿入しない(「画像は保存しましたが、ファイルを切り替えたため参照は挿入していません: <パス>」)

## 3. 画像とテキストの両方がある貼り付け(Excel のセルなど)

- 実機で確認済み: Ctrl+Shift+V ならテキストだけが貼られる(ブラウザが text/plain だけを渡す)
- 案 A: Ctrl+V で画像とテキストの両方があるときだけ、カーソル位置にメニュー
  「画像で貼り付け(Enter / 1)/ テキストで貼り付け(2)/ 表(Markdown)で貼り付け(3)」。Esc・メニューの外のクリックで取り消し。
  表はタブ区切りのときだけ出す。画像だけのときは今までどおり
- 採否はデモページ(test-output/paste-demo.html)で試してもらってから決める。デモでは
  「毎回選ぶ / 常に画像 / 常にテキスト」を切り替えられる(設定にするかもデモを見て決める)

## 4. 表(Markdown)での貼り付けと表の整形

- 表で貼り付け: Excel のタブ区切り(引用セル・セル内改行に対応)を 1 行目が見出しの表に変換。セル内の改行は `<br>`、`|` は `\|`
- 表の整形: Alt+Shift+F(VS Code の「ドキュメントのフォーマット」と同じキー)で文書中の表の列幅を揃える。
  全角文字は幅 2 で数える。配置(`:--` / `--:` / `:-:`)を保つ。コードブロック・引用の中は対象外
- 入口(Alt+Shift+F のほかにボタンを置くか・保存時に自動で整形するか)はデモを見て決める
- 純粋関数は src/md-table.js(単体テスト tests/md-table.test.js)
