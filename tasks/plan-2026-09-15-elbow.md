## 1. エディタを最下部までスクロールしてもプレビューが最下部にならない(不具合)

### 原因(コードで確認)
- `src/scroll-sync.js` の `syncEditorToPreview()` は「エディタの一番上に見えている行」に対応する
  プレビューの要素の位置へスクロールする
- エディタを最下部までスクロールしても、一番上に見えている行は最終行ではなく「最後の 1 画面分の
  先頭の行」。そこから下の内容は、エディタでは 1 画面分でも、プレビューでは画像(md では 1 行、
  プレビューでは数百 px)があるとずっと長くなるため、プレビューは最下部まで届かない
- 画像が末尾付近にあるほど顕著(ユーザーの推測どおり)

### 対応
- エディタの残りのスクロール量が 1 画面分を切ったら、プレビューの目標位置を
  「行の対応で求めた位置」から「プレビューの最下部」へ徐々に寄せる
  - `remain = editorMax - editorScrollTop`、`span = min(editorMax, editorの表示高さ)`
  - `t = 1 - remain / span`(0〜1)、`target = lineTarget + (previewMax - lineTarget) * t`
  - エディタが最下部なら t = 1 でプレビューも最下部。1 画面より上では今までどおり(t = 0)で、
    境目で位置が飛ばない
- プレビュー → エディタ方向は今回も直さない(2026-09-14 のユーザー判断のまま)

### テスト
- E2E(dev/harness.mjs): 末尾に縦に長い画像がある md で、エディタを最下部までスクロール →
  プレビューの scrollTop が最下部(±1px)。文書の途中の同期は既存のセクション 26 のテストが通ること。
  修正前のコードで失敗することも確認する

対象: src/scroll-sync.js、dev/harness.mjs(規模: 小)

## 2. カギ線矢印(Excel の「カギ線矢印コネクタ」)と枠への接続

### 仕様
- ツール「カギ線 (L)」を「矢印 (A)」の隣に追加。ドラッグで描く(直線の矢印と同じ操作)
- 線は水平・垂直の線分だけで結ぶ(折れ曲がりは自動)
  - 両端とも枠につながっていない: 横長にドラッグしたら「横 → 縦 → 横」、縦長なら「縦 → 横 → 縦」。
    中央の線は両端の真ん中
  - 枠につながっている端は、**枠の辺の中点(上下左右の 4 か所)から辺に垂直に出入りする**(Excel と同じ)
  - 曲がる回数が少ない経路を選ぶ(例: 右の辺 → 下の枠の上の辺なら L 字 1 回)。つないだ枠の中を
    線が通り抜けないように回り込む
- **接続のしかた**: 端を枠の上か枠の近く(画面上 10px 以内。今の矢印と同じ)で離すとつながる。
  **どの辺につながるかは、離した位置に一番近い辺**。描き始めの位置が枠の上なら始点もつながる
  - ドラッグ中、つながる予定の枠に接続点(4 つの丸)を表示し、つながる辺の丸を強調する
    (直線の矢印でも、つながる予定の枠の輪郭を強調する。今は何も出ないため分かりにくい)
  - 枠を動かす・大きさを変える・吹き出しの文字が変わると、線も付いてくる
  - つないだ枠を削除すると、その端は今の位置に残って「つながっていない端」になる(今の矢印と同じ)
- 選択ツール: 両端のハンドルで付け替え(離した位置でまたつながる)。**「横 → 縦 → 横」のように
  中央の線がある形のときは、中央の線のハンドルをドラッグして位置を調整できる**(Excel の黄色いハンドル
  と同じ。両端の間の割合で覚えるので、枠を動かしても同じ割合の位置に付いてくる)
- 色・線の太さ・移動・削除・元に戻す・保存と開き直しは今の矢印と同じ
- 直線の矢印のつながり方(枠の中心どうしを結ぶ線と輪郭の交点)は変えない

### データ形式(PNG に埋め込む JSON。version 2 のまま、図形の項目を追加するだけ)
```
{ id, type: 'arrow', routing: 'elbow',            // routing が無い = 直線(今までの矢印)
  from: { x, y, attach, side },                   // side: 'top'|'right'|'bottom'|'left'(つながっているとき)
  to:   { x, y, attach, side },
  mid: 0.5,                                        // 中央の線の位置(両端の間の割合 0〜1。省略時 0.5)
  stroke, strokeWidth }
```
- `type` を `'arrow'` のままにするので、接続・移動・削除の既存の処理がそのまま使える
- 古いアプリでこの PNG を開くと、カギ線は直線の矢印として表示される(焼き込んだ PNG 自体は正しい。
  保存し直すと直線になる)。model.js の変更は不要(shapes は項目をそのまま複写している)

### 経路の計算(shapes.js。DOM 非依存の純粋関数、node:test で検証)
- `routeElbow(start, end, obstacles, mid)` → 点の配列(先頭 = 始点、末尾 = 終点、水平・垂直のみ)
  - start / end: `{ x, y, dir }`。dir はつないだ辺の外向き('top' 等)。つながっていない端は null
  - 両端ともつながっていない: 主な向き(|dx| ≥ |dy| なら横)で dir を決めて「横 → 縦 → 横」にする
  - つないだ端は辺から一定距離(スタブ。16px 程度)まっすぐ出してから曲がる
  - 候補の座標(両端・スタブの先・中央の線 = 両端の間の mid の位置・つないだ枠の辺 ± 余白)で
    疎な格子を作り、「長さ + 曲がる回数 × ペナルティ」が最小の経路をダイクストラで探す
    (つないだ枠を余白ぶん広げた矩形の内側は通れない)。格子は多くても十数 × 十数点なので軽い
- `nearestSide(box, point)`: 点に一番近い辺
- `computeArrowEndpoints` / `getShapeVisualBounds` / `buildShapeSvg` をカギ線に対応
  (見た目の外枠は折れ点と矢じりをすべて含む。描画は `<polyline>`、矢じりの向きは最後の線分)

### エディタ(annotator.js)
- ツール 'elbow'、キー L。描画・端点のドラッグ時に side を決める。当たり判定は折れ線に沿った太い透明線
- 選択時のハンドル: 両端 + 中央の線(ある形のとき)。中央の線のドラッグで mid を更新
- ドラッグ中の接続点の表示(選択レイヤーに描く。出力には入らない)

### テスト
- node:test: 両端つながっていない(横長・縦長・mid)、向かい合う辺(Z 字)、右 → 上(L 字)、
  後ろ向き(相手が逆側)でも枠を通り抜けない、同じ向きの辺(コの字)、線分がすべて水平・垂直、
  `nearestSide`、見た目の外枠
- E2E: 2 つの赤枠をカギ線でつなぐ(side の確認)→ 枠を動かすと付いてくる → 中央のハンドルで調整 →
  保存・開き直しで復元 → 出力 PNG の折れ点付近の画素が線の色

対象: src/annotator/shapes.js、annotator.js、annotator.css、tests/annotator-shapes.test.js、
dev/annotator-harness.mjs(規模: 中〜大)

## 3. 吹き出しの文字の大きさ・色

### 仕様
- ツールバーに「文字」のグループを追加: **文字の大きさ**(選択肢: 12 / 14 / 16 / 18 / 20 / 24 / 28 /
  32 / 40 / 48 / 64 px。既定 24 = 今と同じ)と **文字の色**(黒 #222222 = 今の既定 / 赤 / オレンジ / 青 / 緑)
- 吹き出しを選択中はその吹き出しに適用、何も選んでいないときは次に作る吹き出しの既定になる
  (今の「色」「線の太さ」と同じ動き)。画像の選択中は何もしない
- 吹き出しの中の文字全体が対象(一部の文字だけ色を変えることはできない)
- 枠の色・線の太さは今までどおり「色」「線の太さ」のボタンで変える
- 大きさを変えると枠の大きさも文字に合わせて変わる(つながっている矢印も付いてくる)
- データ形式: 吹き出しは既に `fontSize` と `textColor` を持っている(今は変える UI が無いだけ)。
  形式の変更なし。既存の PNG もそのまま開ける

### テスト
- E2E: 吹き出しを選んで大きさ・色を変える → 枠が大きくなる・文字の色が変わる → 元に戻す →
  保存・開き直しで復元。何も選んでいないときに変えると、次の吹き出しがその大きさ・色になる

対象: src/annotator/annotator.js、annotator.css、dev/annotator-harness.mjs(規模: 小)
